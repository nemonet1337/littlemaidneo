# LittleMaidNeo ユーザードキュメント

Minecraft 26.1 / NeoForge 向けメイドさん Mod の遊び方です。

## 導入

1. NeoForge 26.1.x と Java 25 環境を用意する
2. 配布 jar を `mods/` に入れる
3. （任意）外部ボイス・テクスチャパックはゲームディレクトリの `LMMLResources/` へ

## 基本操作

| 操作 | 効果 |
|------|------|
| 砂糖などで雇用 | 契約（お給料タグのアイテム） |
| 右クリック（空手など） | インベントリを開く |
| 砂糖（お給料） | 回復＋状態変更 |
| 羽 | 移動モード: 護衛 → 自由 → お散歩 → 護衛 |
| 赤石 | 自由/お散歩 ↔ 赤石探知 |
| 棒 | 利き手（右/左）切替 |
| 牛乳 | 全効果解除 |
| 金リンゴ | 回復＋効果 |
| 飲むポーション | 効果付与（瓶返却） |
| ガラス瓶 | 経験値瓶に変換（複数可） |

## 移動モード

- **護衛 (Escort)**: ご主人に追従
- **自由 (Freedom)**: 指定地点周辺を徘徊
- **お散歩 (Stroll)**: ご主人の周辺をゆっくり散歩
- **赤石探知 (Tracer)**: 赤石信号を辿る

インベントリ画面左の羽ボタンでも切り替えできます。待機中・ストライキ中は専用表示になります。

## お仕事

メインハンド／インベントリの道具で自動切替:

- 剣・斧など → 剣士、弓 → 弓兵
- 料理・毛刈り・照明・回復・調合 など

表示名は「護衛剣士」「自由弓兵」のように移動×お仕事でまとめて出ます。

## お給料

未払いが続くとストライキになります。GUI に未払い日数／ストライキ表示があります。砂糖などのお給料アイテムを渡してください。

## コマンド（OP）

| コマンド | 内容 |
|----------|------|
| `/lmn reload` | 外部リソース再読込 |
| `/lmn models list` | モデル一覧 |
| `/lmn maid count` | 付近のメイドさん数 |
| `/lmn maid tp` | 自分のメイドさんを呼び寄せ |
| `/lmn config bake` | コンフィグを再 bake（サーバー設定の再適用） |
| `/lmn debug dump` | デバッグ情報 |

## 外部 Mod 向け API

`work.nemonet.littlemaidneo.api.LittleMaidAPI` に問い合わせ用の薄い API があります。

```java
LittleMaidAPI.asMaid(entity).ifPresent(maid -> {
    if (LittleMaidAPI.isOwnedBy(maid, player)) {
        LittleMaidAPI.setMovingMode(maid, MaidMode.ESCORT);
    }
});
```

## トラブルシュート

- ボイスが出ない: `LMMLResources/` にパックがあるか、Zip かフォルダ形式かを確認
- 赤石で迷う: 到達可能な経路上に信号があるか確認（障害物）
- マルチで表示がおかしい: 再ログイン／`/lmn config bake`
