# MC 26.3 / NeoForge 26.3.0.64-beta への移行

- ステータス: 承認・実施済み
- 日付: 2026-10-10
- 対象バージョン: Minecraft 26.3、NeoForge 26.3.0.64-beta、FML 12.0.9

## Context

PrismLauncher 側の検証環境が「Latest NeoForge」= MC 26.3 + NeoForge 26.3.0.64-beta に更新されたため、本 Mod も 26.3 で動作させる必要があった。既存コードは MC 26.2 / NeoForge 26.2.0.87 向けで、バージョン変更により 100 件規模の API 破損が発生した。

## Decision

`gradle.properties` を MC 26.3 / NeoForge 26.3.0.64-beta に更新し、破損 API を 26.3 の現行 API へ移植した。主な対応は以下の通り。

### バニラ API の主な変更点

| 26.2（旧） | 26.3（新） | 備考 |
| --- | --- | --- |
| `PoseStack.mulPose(Quaternionf)` | `PoseStack.rotateDegrees(Axis, float)` / `rotate(Quaternionfc)` | mulPose は `Matrix4fc` / `Transformation` 専用に。`PoseStack` は `com.mojang.blaze3d.vertex` に移動 |
| `EntityRenderDispatcher.getItemInHandRenderer()` | `ItemModelResolver` + `ItemStackRenderState.submit(...)` | `ItemInHandRenderer` クラス自体が削除。`Minecraft.getItemModelResolver()` 経由で `updateForLiving` 後に提出 |
| `org.lwjgl.glfw.GLFW.GLFW_*` | `com.mojang.blaze3d.platform.InputConstants` | キー定数は `InputConstants.KEY_*` / `MOUSE_BUTTON_*` |
| `Pack.ResourcesSupplier#openPrimary/openFull` | `openMetadata(PackLocationInfo)` + `openResources(PackLocationInfo, Metadata)` | `PackMetadataResources` が差異吸収型に。`ResourceWrapper` は `getMetadataSection` を持つのでそのまま返せる |
| `LivingEntity.swing(InteractionHand)` | `Mob.swing(InteractionHand, SwingAnimation)` | アニメ明示。`SwingAnimation.DEFAULT` が旧 1 引数版と等価 |
| `LivingEntity.getAttackAnim(float)` / `swingingArm` | `getSwingAnimation(float)` + `getCurrentSwing()` | swing 状態は `LivingEntity.SwingState` に移動 |
| `Level.fuelValues().isFuel(stack)` | `stack.has(DataComponents.COOKING_FUEL)` | データドリブン化 |
| `Level.potionBrewing()` | `level.recipeAccess().getRecipeFor(RecipeType.BREWING, BrewingInput, level)` | `RecipePropertySet.BREWING_REAGENTS` と併用 |
| `stack.getItem() instanceof AxeItem` | `stack.is(ItemTags.AXES)` | `AxeItem` クラス削除、タグ判定へ |
| `Entity.invulnerableTime`（private 化） | `LivingEntity.hurtTime`（public） | 直近被ダメージ判定は `hurtTime` を使用 |
| `PushReaction.IGNORE` | `PushReaction.IGNORE_ENTITY` | `IMMOVEABLE` は別用途（押せないが他を押す） |
| `Player.drop(stack, bool)` | `Player.drop(stack, bool, Prediction)` | サーバー側は `Prediction.SERVER_ONLY` |
| `Block.simpleCodec(Function)` | `BlockBehaviour.propertiesCodec(...)` | 簡易ブロックの CODEC 作成方法 |

### NeoForge / FML の主な変更点

| 26.2（旧） | 26.3（新） | 備考 |
| --- | --- | --- |
| `ModConfig.Type.COMMON` / `SERVER` | `ModConfig.Type.LOCAL` / `SYNCED` | FML 12 で再編。CLIENT / STARTUP は据え置き |
| `ModContainer.registerConfig` | シグネチャ不変 | 渡す `Type` のみ変更 |
| `Event.createProvider(DataProviderFromOutput)` / `createProvider(DataProviderFromOutputLookup)` | 同形 | コンストラクタ参照 `(output)` / `(output, lookup)` はそのまま |
| `event.recipe(recipeCtx -> ...)` | 同形 | `RecipeProvider(Runnable, ...)` 経由に移行 |
| `context.recipe(ctx).save(consumer, id)` | `context.recipe(holder).build(consumer, id)` | レシピ出力 API が変更 |
| `event.lootTable(provider)` | `event.lootTable(SubProviderEntry, SubProviderEntry...)` | `SubProviderEntry(Factory, ContextKeySet)` の可変長 |
| `event.advancement(provider)` | `event.advancement(Factory...)` | `AdvancementSubProvider` は abstract class、`Builder.display(DisplayInfo)` |
| `recipe_unlocked` の `"recipe"` | `"recipes"` | Advancement JSON のフィールド名変更 |
| `MobSpawnSettings.SpawnerData(EntityType, int, int)` | `SpawnerData(EntityType, IntProvider)` | `UniformInt.of(min, max)` |
| `EntityPredicate.ADVANCEMENT_CODEC` | `EntityPredicate.wrap(ContextAwarePredicate)` | 条件ラップ形式に変更 |
| `DatapackBuiltinEntriesProvider(...)` | `DatapackBuiltinEntriesProvider(output, String, Collection<RegistryData<?>>, lookup, Set<String>)` | RegistrySetBuilder を RegistryData 化して渡す |

### データ生成の出力分離（重要）

26.3 の `HashCache` は実行ごとに出力ディレクトリ内の未生成ファイルを stale として削除する。clientData / serverData の両ランが同一の `src/generated/resources/` を `--output` に使うと、後実行のランが先実行のランの生成物（タグ・データマップ・バイオームモディファイア等 24 ファイル）を削除してしまう。

そのため `apps/mods/build.gradle.kts` の run 設定を変更:

- clientData: `--output build/generated/client`
- serverData: `--output build/generated/server`
- `mergeData`（従来定義あり、NO-SOURCE 状態だった）が両者を `src/generated/resources/` へ Copy

## Notes

- `neoforge/biome_modifier/maid_spawn.json` を生成するプロバイダは現存しないため、既存ファイルを git で維持（内容は現行の BiomeModifier JSON 仕様そのまま）。`#littlemaidneo:maid_spawn_biome` タグは datagen で再生成されるため依存関係は維持される。
- PrismLauncher の「Latest NeoForge」インスタンスは MC 26.3 / NeoForge 26.3.0.64-beta で一致。検証用に 4GB ヒープ設定（`MaxMemory=4096`）へ変更した。既定の 12GB 設定では他アプリ起動中は Prism の低メモリ警告ダイアログで停止する。
- 開発実行（`:apps:mods:runClient`）での動作確認済み: Mod List に `LittleMaidNeo 1.1.6 (littlemaidneo)`、Mixin 適用、コンフィグ読み込み、リソースリロード（`mod/littlemaidneo` + `LMModelLoader`）までエラーなし。
